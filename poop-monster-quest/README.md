# 💩 똥괴물 대소동: 마을을 구해라!

초등학생을 위한 3D 웹 어드벤처 미니게임이에요. 빌드 도구 없이 브라우저에서 바로 실행됩니다 (Three.js CDN 사용).

## 실행 방법

파일을 더블클릭해서 열어도 되고, 아래처럼 로컬 서버로 열어도 됩니다.

```bash
cd poop-monster-quest
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

GitHub Pages로 배포하려면 저장소 설정에서 Pages 소스를 이 폴더(또는 `main` 브랜치 루트)로 지정하면 됩니다.

## 게임 소개

똥괴물들이 마을을 온통 더럽혀 놓았어요! 용사가 되어 똥괴물을 물리치고, 우리에 갇힌 친구들을 구출해서 마을을 다시 깨끗하게 만들어주세요.

- **핵심 루프**: 탐험 → 전투 → 보상 획득 → 마을 정화 → 친구 구출 → 승리
- **장르/시점**: 3D 탑다운 액션 어드벤처
- **조작**: 키보드 + 마우스

## 조작 방법

| 키 | 동작 |
| --- | --- |
| `W` `A` `S` `D` | 이동 |
| 마우스 왼쪽 클릭 | 칼 던지기 (똥괴물 공격 / 날아오는 똥 없애기) |
| `Space` | 칼 휘두르기 (사거리 내 날아오는 똥을 튕겨내서 되받아치기) |
| `I` | 인벤토리 열기/닫기 |
| `K` | 스킬트리 열기/닫기 |

## 게임 시스템

- **체력 / 에너지**: 똥에 맞으면 체력이 줄고 이동 속도가 잠시 느려지며 에너지도 감소해요.
- **인벤토리**: 몬스터를 처치하면 코인, 회복 물약, 에너지 물약을 드랍합니다. 인벤토리 창에서 물약을 사용할 수 있어요.
- **스킬트리**: 코인을 모아 공격력 / 이동속도 / 에너지 회복 속도를 강화할 수 있어요.
- **승리 조건**: 마을의 모든 똥괴물을 물리치고, 갇혀있는 친구를 모두 구출하면 승리!
- **패배 조건**: 체력이 0이 되면 게임 오버 (다시 도전 버튼으로 재시작).

## 기술 스택

- Three.js (CDN, 빌드 불필요)
- 순수 JavaScript / HTML / CSS
- Web Audio API로 효과음을 직접 합성 (외부 음원 파일 없음 — 요청사항에 따라 배경음악 없이 효과음만 포함)

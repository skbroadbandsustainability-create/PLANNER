# 🐑 민주호의 동물농장

자연을 탐험하며 동물을 찾고, 밧줄로 데려와 농장 울타리 안에서 길러보는 3D 웹 게임입니다.
Three.js + TypeScript + Vite로 만들었고, 별도 이미지/오디오 파일 없이 모든 3D 모델과 효과음을
코드로 절차적 생성합니다.

> PLANNER 저장소 안의 독립된 서브 프로젝트입니다. 루트의 "공부 계획표" 앱과는 완전히 별개이며,
> 이 폴더(`animal-farm/`) 안에서 직접 설치/실행/빌드합니다.

## 실행 방법

```bash
cd animal-farm
npm install
npm run dev      # 개발 서버 실행 후 안내되는 주소로 접속
npm run build    # 프로덕션 빌드 (dist/ 생성)
npm run preview  # 빌드 결과 미리보기
npm run lint     # oxlint 검사
```

## 조작법

| 입력 | 동작 |
| --- | --- |
| ↑ ↓ ← → (또는 W A S D) | 이동 |
| Space | 점프 |
| 마우스 좌클릭 | 가까운 야생 동물에게 밧줄 던지기 (포획) |
| 마우스 우클릭 / Q | 밧줄 풀기 |
| F (또는 E) | 근처 NPC와 상호작용 (상점 열기) |
| I | 인벤토리 / 제작 |
| L | 퀘스트 로그 |
| K | 스킬 트리 |
| Esc | 열린 창 닫기 |

## 핵심 루프

**자연 탐험 → 동물 찾기 → 밧줄로 포획 → 농장 울타리로 데려오기 → 기르기 → 다음 탐험**

농장 허브를 중심으로 4개의 자연 지역(초원 / 바다 / 산 / 강)이 배치되어 있고, 지역마다 다른
동물들이 서식합니다. 동물에게 다가가 클릭하면 밧줄을 던져 포획하고, 포획된 동물은 플레이어를
따라오며 농장 울타리 안으로 들어오면 자동으로 사육 상태가 되어 XP와 재료를 보상으로 받습니다.

| 지역 | 동물 (10종) |
| --- | --- |
| 🌾 초원 | 토끼, 닭, 양, 소, 말, 두더지, 거위, 칠면조, 당나귀, 종달새 |
| 🌊 바다 | 게, 물범, 갈매기, 펠리컨, 불가사리, 바다거북, 문어, 조개, 해달, 물떼새 |
| ⛰️ 산 | 염소, 여우, 늑대, 곰, 사슴, 다람쥐, 독수리, 부엉이, 산양, 스라소니 |
| 🏞️ 강 | 수달, 개구리, 비버, 왜가리, 오리, 잉어, 자라, 송어, 잠자리, 뱀 |

총 40종. 물범/펠리컨/바다거북/해달/여우/늑대/사슴/독수리/비버/송어/뱀은 1단계 밧줄(강화 밧줄) 이상이,
곰/스라소니/문어/왜가리는 2단계 밧줄(황금 올가미)이 있어야 포획할 수 있는 희귀 동물입니다.

## 시스템

- **레벨업**: 동물을 농장에 데려올 때마다 XP 획득, 레벨업 시 스킬 포인트 지급
- **인벤토리**: 동물이 주는 재료(양털/깃털/조개/갈대/모피)와 사료를 보관
- **장비 조합(밧줄 강화)**: 재료를 모아 밧줄을 상위 등급으로 제작 → 포획 사거리·끄는 속도 증가,
  희귀 동물(곰, 문어, 왜가리 등) 포획에 필요
- **스킬 트리**: 걸음 숙련(이동속도) · 밧줄 숙달(사거리) · 동물 친화(끄는 속도) · 우리 확장(수용량)
  · 다중 포획(동시 포획 수) 5개 노드
- **퀘스트 시스템**: 동물 종류별로 구조 목표(1단계 2마리 / 2단계 5마리) 부여, 완료 시 보상
- **NPC 상점**: 사료 가게 아저씨가 재료 ↔ 사료 ↔ 밧줄실 물물교환 제공

## 비주얼 & 사운드

- 모든 캐릭터/동물/지형/소품은 Three.js 기본 도형(구, 원뿔, 실린더, 상자 등)을 조합한
  로우폴리 스타일로 절차적 생성 (외부 3D 모델/텍스처 파일 없음)
- 주인공 "민주호", NPC "사료 가게 아저씨" 캐릭터 포함
- 동물 포획/농장 배달 시 파티클 획득 이펙트 표시
- 배경음악 없음. 동물 울음 효과음은 Web Audio API 오실레이터로 종별로 다르게 즉석 합성
  (별도 오디오 파일 불필요)

## 프로젝트 구조

```
src/
  core/       게임 데이터(종/바이옴/퀘스트/스킬/레시피 정의)와 GameState
  world/      월드 구성(지형/바이옴/소품), 동물 AI, NPC
  player/     플레이어 이동/점프, 밧줄 포획 컨트롤러
  ui/         HUD, 인벤토리, 스킬트리, 퀘스트 로그, 상점 패널 (DOM 기반)
  fx/         획득 파티클 이펙트
  audio/      동물 울음 SFX 합성
  main.ts     전체 게임 루프 초기화/연결
```

## 알려진 단순화 사항 (향후 확장 아이디어)

- 울타리 기둥은 시각적 요소이며 실제 충돌은 없습니다 (배달 판정은 농장 중심으로부터의 거리 기준).
- 동물 종별 3D 모델은 기본 도형 조합으로 단순화되어 있습니다. 더 정교한 모델/애니메이션으로
  교체할 수 있습니다.
- 저장/불러오기(localStorage) 기능은 아직 없습니다. 새로고침하면 진행 상황이 초기화됩니다.
- 모바일 터치 조작은 미지원입니다 (키보드 + 마우스 전제).

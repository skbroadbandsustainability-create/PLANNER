# PLANNER

공부 계획

아이가 태블릿에서 스스로 오늘의 공부 계획을 확인하고 체크할 수 있는 앱이에요.

## 주요 기능

- **오늘**: 날짜/시간/과목/할 일이 담긴 오늘의 계획을 큼직한 버튼으로 체크
- **이번 주**: 요일별 완료/미완료 개수와 완료율, 아직 못한 과제 목록을 확인
- **참 잘했어요 도장 + 보상**: 하루 계획을 모두 끝내면 도장과 함께 별을 획득하고, 별을 모아 부모님이 설정한 보상을 받을 수 있어요
- **계획 관리**: 부모가 날짜/시간/과목/할 일을 등록·수정·삭제 (요일 반복 등록 지원)

모든 데이터는 기기(브라우저)에 안전하게 저장돼요.

## 개발

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
npm run lint     # 린트 검사
```

React + TypeScript + Vite + Tailwind CSS로 만들었고, 태블릿 화면에 맞춰 반응형으로 디자인했어요.

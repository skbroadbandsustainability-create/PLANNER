# PLANNER

공부 계획

아이가 태블릿에서 스스로 오늘의 공부 계획을 확인하고 체크할 수 있는 앱이에요.

## 주요 기능

- **오늘**: 날짜/시간/과목/할 일이 담긴 오늘의 계획을 큼직한 버튼으로 체크
- **이번 주**: 요일별 완료/미완료 개수와 완료율, 아직 못한 과제 목록을 확인
- **참 잘했어요 도장 + 보상**: 하루 계획을 모두 끝내면 도장과 함께 별을 획득하고, 별을 모아 부모님이 설정한 보상을 받을 수 있어요
- **계획 관리**: 부모가 날짜/시간/과목/할 일을 등록·수정·삭제 (요일 반복 등록 지원)

모든 데이터는 기기(브라우저)에 안전하게 저장돼요.

## 개발

```bash
npm install
npm run dev      # 개발 서버 실행
npm run build    # 프로덕션 빌드
npm run lint     # 린트 검사
```

React + TypeScript + Vite + Tailwind CSS로 만들었고, 태블릿 화면에 맞춰 반응형으로 디자인했어요.

## 🎾 몬스터 테니스 챔피언십 (미니게임)

같은 저장소에 얹혀 있는 별도의 미니게임이에요. 개발 서버 실행 중 `/tennis.html`
로 접속하면 플레이할 수 있어요 (예: `http://localhost:5173/tennis.html`).

- 아비스나가(물/그림자) / 드럼조우(풀/격투) / 이그니스피어(불꽃/에스퍼) 중 하나를 골라
  키보드로 즐기는 3D 테니스 게임 (Three.js 렌더링)
- 이동: 방향키/WASD, 스매시: Space, 스킬: J/K, 메가진화: L
- 경기에서 이기면 돈을 벌고, 상점에서 스킬을 해금·강화하거나 캐릭터를 레벨업할 수 있어요
- React 앱과는 완전히 독립적으로 동작하는 순수 TypeScript + Three.js 게임이에요 (`src/tennis/`).
  three.js는 cdnjs CDN에서 로드하며 리포지토리 번들에는 포함되지 않아요.
